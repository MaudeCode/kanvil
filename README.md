# Kanvil

Self-hosted ticketing for people and agents, with web and native mobile apps, local and OIDC login, a realtime API, and MCP tools.

Kanvil owns its ticket data and runs on your infrastructure. PocketID is the initial OIDC provider targeted for validation.

## Status

Repository setup only. The application is not implemented yet.
